# Blog Post Template

## Structure

### 1. Opening Hook (2-3 sentences)
- Start with a problem, pain, or surprising fact
- Make the reader think "I have this problem too"
- NEVER start with "In this post, I will..."

### 2. Context (1-2 paragraphs)
- What were you trying to do?
- Why was it important?
- What did you expect to happen?

### 3. The Journey (3-5 sections)
- What you tried first and why it failed
- What you tried second and why it failed  
- What actually worked
- Include real code snippets, error messages, architecture decisions

### 4. The Insight (1-2 paragraphs)
- What did you learn that others can apply?
- What's the non-obvious takeaway?
- Why does this matter beyond your specific case?

### 5. Downsides & Limitations (1 paragraph)
- Where does this approach fall short?
- What would you do differently next time?
- Be honest — this builds trust

### 6. What's Next (1-2 sentences)
- Where are you taking this work next?
- Open questions or areas to explore

## Formatting Rules
- Use real code from the project (not toy examples)
- Include diagrams where helpful (generate with AI)
- Keep paragraphs to 3-4 sentences max
- Use headers liberally — every 200-300 words
- Bold key terms on first use

## Length: 1500-3000 words
