# Tutorial Template

## Structure

### 1. What You'll Build (2-3 sentences)
- Clear outcome the reader will achieve
- Prerequisites (what they need before starting)
- Time estimate

### 2. Setup (if needed)
- Installation commands
- Environment setup
- Keep minimal — only what's required

### 3. Step-by-Step Build (5-10 steps)
Each step:
- What we're doing (1 sentence)
- Code block with real code (copy-pasteable)
- What happened (1-2 sentences explaining the result)
- Common errors and how to fix them

### 4. What Went Wrong (1-2 paragraphs)
- Share what failed during development
- Explain the debugging process
- This is what separates tutorials from docs

### 5. Running the Result
- How to run/test what was built
- Expected output shown

### 6. Next Steps (2-3 bullet points)
- Where to take this further
- Links to related resources

## Formatting Rules
- Every code block must be copy-pasteable and runnable
- Show expected output after each code block
- Use `⚠️` for common pitfalls
- Use `💡` for tips from real experience

## Length: 1000-2500 words
